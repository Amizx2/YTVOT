# YTVOT — Автономный мод голосового перевода для YouTube на iOS

**YTVOT** — это независимый, автономный iOS-твик, добавляющий синхронный нейросетевой голосовой перевод видео в официальное приложение YouTube на iPhone и iPad.

Проект основан на наработках [voice-over-translation](https://github.com/ilyhalight/voice-over-translation) и [vot.js](https://github.com/FOSWLY/vot.js), но полностью переписан на чистый Objective-C++ / UIKit и отделен от любых сторонних твиков.

Мод собирается в виде отдельной динамической библиотеки `YTVOT.dylib` и rootless `.deb` пакета. Его можно внедрить в **любой** YouTube: чистый оригинальный клиент, YTKACE, YTLite, uYouEnhanced и др.

---

## Возможности

- **Универсальная совместимость**: работает как со стоковым YouTube, так и с модифицированными сборками.
- **Синхронизация звука через Phase-Locked Loop (PLL)**: устраняет рассинхрон аудиодорожки. Микро-коррекции скорости ($\pm 12\%$) плавно удерживают речь синхронно с видеорядом.
- **Умное адаптивное приглушение (Smart Adaptive Ducking)**: фоновый сканер аудиофайла (`AVAssetReader`) определяет точные интервалы речи. Оригинальный звук видео приглушается **только когда говорит переводчик**, и плавно нарастает в паузах.
- **Выбор голоса**: мужской, женский или автоматический.
- **Языки перевода**: русский, английский, казахский.
- **Кнопка на плеере**:
  - **Одиночный тап**: включение и отключение перевода.
  - **Долгое нажатие (long-press)**: открытие окна настроек YTVOT.
- **Интеграция в меню видео**: пункт быстрого перевода прямо в стандартном меню действий плеера.
- **Интеграция в настройки YouTube**: раздел YTVOT в главном меню настроек приложения.
- **Авторизация в Яндекс**: встроенный вход через OAuth (WKWebView) для длинных видео.

## Установка

### Вариант 1: Через Sideloadly или ESign (без джейлбрейка)
1. Скачайте исходный `.ipa` файл YouTube.
2. В Sideloadly или ESign выберите «Inject Dylib» / «Внедрить dylib».
3. Выберите `YTVOT.dylib`.
4. Подпишите и установите IPA на устройство.

### Вариант 2: TrollStore / Джейлбрейк (.deb)
1. Установите `com.amizx2.ytvot_1.0.0_iphoneos-arm64.deb` через TrollStore, Sileo или Zebra.
2. Перезапустите YouTube.

### Вариант 3: Автоматическая сборка IPA на macOS (в 1 клик)
Скрипт `build_macos.sh` автоматически распаковывает чистый YouTube IPA, внедряет `YTVOT.dylib`, прописывает команду загрузки в бинарник, подписывает ad-hoc сертификатом и упаковывает готовый к установке `YouTube_VOT.ipa`:

```bash
git clone https://github.com/Amizx2/YTVOT.git
cd YTVOT

# Поместите файл YouTube.ipa в папку с проектом
chmod +x build_macos.sh
./build_macos.sh YouTube.ipa
```

Если требуется также перекомпилировать `YTVOT.dylib` из исходников на Mac:
```bash
./build_macos.sh --compile YouTube.ipa
```

## Сборка из исходников (Theos / Kali / Linux)

```bash
chmod +x build_kali.sh
./build_kali.sh
```

Скрипт автоматически скачает Theos и iOS SDK, скомпилирует `.deb` пакет и извлечет готовый `YTVOT.dylib`.
